Project: Motherboard - Help

🎯 Core Concept

Build your projects like electronic circuits. Drag components from the Parts Tray onto the workbench, connect them with traces, and watch energy flow through your completed work.

🧩 Components

✨ Power Core: Your user stories - the energy source that powers everything

⬛ Module IC: Features or services - black boxes with defined interfaces

▬▬ Task Resistor: Individual tasks - the atomic units of work

🎮 Controls

Drag components from the Parts Tray to place them

Click components to edit their properties

Double-click Module ICs to enter their internal schematic view

Double-click Task Resistors to cycle through status

Click pins to start/end connections (⚡ Smart Soldering Iron)

Right-click + Drag to pan the workbench

Mouse Wheel to zoom in/out

🏗️ Module IC System

Hierarchical Design: Module ICs contain internal circuits

Enter Schematic: Double-click Module ICs to zoom into their internals

Internal Building: Place Task Resistors inside Module ICs

Navigation: Use the Back button or breadcrumbs to return to main board

State Aggregation: Module outline reflects internal component status

⚡ Connections & Energy Flow

Smart Soldering Iron: Click any pin to start a connection, then click another pin to complete it

Data Flow: IN PROGRESS components send pulsing data packets through traces

Power Flow: DONE components send steady, bright energy with data bursts

Color-Coded Traces: Each category has its own color (Frontend=Green, Backend=Blue, etc.)

Pin Activity: Active pins glow and pulse when transmitting/receiving data

Visual Feedback: Watch data cascade through your project workflow!

🎨 Categories

Components have categories that determine pin colors and trace types:

Frontend, Backend, Database, Security, Testing, DevOps, Design, Research
